## 🚀 О проекте
Это адаптивный лендинг, созданный для демонстрации навыков в разработке AI-инструментов, работе с данными и бэкенд-разработке. Сайт включает в себя:
*   Описание стека технологий.
*   Портфолио реализованных проектов (AI-транскрибатор, Аналитик продаж, AI-контент-мейкер и др.).
*   Блок с контактами для связи.

## 🛠 Технологии
*   **HTML5** — семантическая верстка.
*   **CSS3** — адаптивный дизайн (Flexbox, Grid, CSS-переменные), плавные анимации.
*   **JavaScript** — интерактивное мобильное меню, анимации появления элементов при скролле (Intersection Observer).
*   **GitHub Pages** — хостинг и деплой.

## 📱 Адаптивность
Сайт полностью адаптирован под мобильные устройства, планшеты и десктопы.
