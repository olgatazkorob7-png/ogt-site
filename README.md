## 🛠 Техническое устройство сайта

* **Чистый HTML5 и CSS3** без тяжёлых зависимостей и фреймворков (быстрая загрузка).
* **Доступность (A11y):** соответствие стандарту WCAG 2.1 AA (0 нарушений в axe-core).
* **Векторная графика:** все иконки и стрелки переведены в inline SVG без риска пропажи глифов.
* **Системные шрифты:** стек с безопасными фолбэками (`-apple-system`, `Segoe UI`, `Roboto`).
* **Интерактивный квиз:** 3-шаговая форма подбора решения с валидацией, защитой от спама и отправкой через Formspree.
* **SEO-гигиена:** семантические теги, Open Graph, JSON-LD (Schema.org Person / ProfessionalService), `robots.txt`, `sitemap.xml`, `404.html`.
