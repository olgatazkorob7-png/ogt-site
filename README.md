## Техническое устройство сайта

- **Чистый HTML5, CSS3 и модульный Vanilla JS** без тяжёлых зависимостей и фреймворков; стили, скрипты, векторный логотип (`assets/img/ogt-logo.svg`) и оптимизированные изображения вынесены в `assets/`.
- **Доступность (A11y):** соответствие стандарту WCAG 2.1 AA (контраст, иерархия заголовков, клавиатурная навигация, `aria`-атрибуты, поддержка `prefers-reduced-motion`).
- **Локальные шрифты:** `Inter` и `Manrope` (WOFF2, `font-display: swap`) размещены локально в `assets/fonts/` — без внешних запросов до согласия пользователя.
- **Интерактивная анкета:** 3-шаговая форма оценки задачи с валидацией, защитой от спама, нативным `POST` fallback без JS и отправкой через Formspree.
- **SEO и метаданные:** семантическая разметка, Open Graph (`1200×630` JPEG), JSON-LD (Schema.org `Person` / `ProfessionalService`), `robots.txt`, `sitemap.xml`, `404.html`.
