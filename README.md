## 📖 О проекте

Этот сайт создан для демонстрации моих навыков в разработке AI-сервисов, бэкенда на Python и аналитики данных. Здесь собраны реальные кейсы — от умных консультантов до BI-дашбордов.

**Основная цель сайта:** показать заказчикам и рекрутерам, как я решаю бизнес-задачи с помощью кода и нейросетей, а не просто перечислить список технологий.

## ✨ Ключевые особенности

*   **Адаптивный дизайн:** Сайт идеально выглядит как на десктопе, так и на мобильных устройствах.
*   **Фильтрация проектов:** Интерактивный фильтр по стеку технологий (Python, AI/LLM, Frontend) на чистом JavaScript.
*   **Структурированные кейсы:** Проекты разделены на «Флагманские» и «Дополнительные», каждый описан по формуле «Боль → Решение → Результат».
*   **Темная тема:** Стильный дизайн с золотыми акцентами (Dark Mode).
*   **Прозрачность:** Раздел «Как я работаю» описывает процесс от брифа до деплоя.

## 🛠 Стек технологий

Проект написан на чистом коде без использования тяжелых фреймворков, что обеспечивает высокую скорость загрузки:
*   **HTML5** — семантическая верстка.
*   **CSS3** — адаптивность (Flexbox, Grid), кастомные анимации и стили.
*   **JavaScript (ES6+)** — логика фильтрации проектов, интерактивное мобильное меню.
*   **GitHub Pages** — хостинг и автоматический деплой.
